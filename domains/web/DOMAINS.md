# Domains

<!-- Meaning -->

## Domains & Extensions Registry

> A web address or a collection of network computers organized under a single name and rules. For example, `.com` or `.org` are top-level extensions in a web domain [1^](https://dictionary.cambridge.org/us/dictionary/english/domain).

## Submission Templates

If you would like to request a new domain or extension addition in the PR tab which is by cloning this, and editing either the /web or /ext folder depending on your request. which will or can be changed if [either](RULES.md), please use one of the templates below.

### Option 1: Standard Request

```markdown
## Request

- [ ] <!-- Domain --> Is it a [*Domain*?](DOMAINS.md)
- [ ] <!-- Extension --> Is it an [*Extension*?](DOMAINS.md)

<!-- List your Extension/Domain -->
> **Extension/Domain:** `example.com` or `.ext`
> **Reason:** Provide the justification or use case here.

```

## Option 2: Quick Request (For "Lazy" Submissions)

### Request

- [ ] <!-- Domain --> Is it a [*Domain*?](DOMAINS.md)
- [ ] <!-- Extension --> Is it an [*Extension*?](DOMAINS.md)
